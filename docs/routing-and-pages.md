# 🗺️ Enrutamiento y Páginas en Bustatic

Bustatic implementa un sistema de **enrutamiento basado en archivos (*file-based routing*)** donde la jerarquía dentro de la carpeta `pages/` define directamente las URLs públicas de tu sitio web.

---

## 📄 Páginas Estáticas y URLs Limpias

Cualquier archivo `.html` colocado dentro del directorio `pages/` se convierte automáticamente en una página web con **URLs limpias (*Clean URLs*)** (sin extensiones `.html` visibles):

| Archivo en `pages/` | URL Pública en Navegador | Archivo Generado en `dist/` |
| :--- | :--- | :--- |
| `pages/index.html` | `/` | `dist/index.html` |
| `pages/about.html` | `/about` | `dist/about/index.html` |
| `pages/contacto.html` | `/contacto` | `dist/contacto/index.html` |
| `pages/legal/privacidad.html` | `/legal/privacidad` | `dist/legal/privacidad/index.html` |
| `pages/blog/index.html` | `/blog` | `dist/blog/index.html` |

> [!NOTE]
> La generación de `dist/[ruta]/index.html` garantiza compatibilidad inmediata con cualquier servidor HTTP o CDN moderno (Cloudflare Pages, Vercel, Netlify, Nginx, Apache, S3).

---

## ⚡ Enrutamiento Dinámico con Parámetros (`[param]`)

Para crear páginas a partir de fuentes de datos (bases de datos, APIs, catálogos), Bustatic utiliza la convención de corchetes `[parametro]`:

### 1. Parámetros Simples:
Crea `pages/blog/[slug].html`:
- Permite generar rutas como `/blog/mi-primer-post`, `/blog/novedades-2026`, etc.

### 2. Múltiples Parámetros Anidados:
Crea `pages/productos/[categoria]/[id].html`:
- Genera rutas jerárquicas como `/productos/electronica/teclado-mecanico` o `/productos/ropa/camisa-lino`.

### Requisito: Loader de Datos Co-ubicado
Toda página dinámica con parámetros **debe tener un loader de datos hermano** con el mismo nombre base (`.data.ts` o `.data.js`):
```text
pages/blog/
├── [slug].html     # Plantilla visual
└── [slug].data.ts   # Fuente de parámetros y props
```

Si creas una plantilla dinámica sin su correspondiente loader hermano, Bustatic detiene la compilación y emite un mensaje de error explicativo con la ruta exacta que debes crear.

---

## 🛡️ Validación Estricta de Parámetros y Seguridad

Para garantizar URLs limpias, seguras y válidas:
- Los parámetros solo pueden contener caracteres alfanuméricos, guiones y guiones bajos (`[a-zA-Z0-9_-]`).
- Bustatic rechaza y detiene el build si un parámetro está vacío, contiene secuencias de salto de directorio (`..`, `/`), o caracteres de control maliciosos.

---

## 🚫 Detección Preventiva de Colisiones de URLs

Si por diseño dos archivos generan la misma URL limpia:
```text
pages/blog/destacado.html           -> /blog/destacado
pages/blog/[slug].html (slug: "destacado") -> /blog/destacado
```

Bustatic realiza un análisis en memoria antes de escribir en disco y emite un error de colisión detallado:

```text
[Bustatic Collision Error]: Duplicate route generated for "/blog/destacado".
  - First generated by: pages/blog/destacado.html
  - Conflicting with:   pages/blog/[slug].data.ts (params: {"slug":"destacado"})
```

---

## 💡 Experiencia en Desarrollo: Página 404 Asistida

Durante la ejecución de `bustatic dev`:
1. **Resolución en Vivo:** Cualquier ruta dinámica o estática recién añadida está disponible de inmediato sin reiniciar el servidor.
2. **Página 404 Asistida:** Si navegas a una ruta inexistente, Bustatic te muestra una página interactiva con el listado completo y enlaces clicables a todas las rutas disponibles en tu proyecto:

```text
404 - Página no encontrada
La ruta solicitada "/blog/articulo-viejo" no coincide con ninguna página.

Rutas disponibles en este proyecto (4):
- / (pages/index.html)
- /about (pages/about.html)
- /blog/mi-primer-post (pages/blog/[slug].html)
- /blog/segundo-post (pages/blog/[slug].html)
```
