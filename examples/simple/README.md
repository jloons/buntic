# ⚡ Buntic Simple Example

Ejemplo sencillo y 100% estático creado con **Buntic**.

---

## 📁 Estructura con `src/`

```text
examples/simple/
├── src/
│   ├── pages/         # index.html, about.html, contact.html
│   ├── layouts/       # main.html
│   ├── components/    # header, footer, card (HTML + CSS scoped)
│   ├── data/          # site.json, features.json
│   ├── styles/        # main.css
│   └── public/        # robots.txt, buntic-icon.svg
├── buntic.config.ts
└── package.json
```

---

## 🚀 Comandos

```bash
# Servidor de desarrollo con live-reload
bun run dev

# Compilar para producción en dist/
bun run build
```
